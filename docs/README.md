# EchoLingua Documentation Bundle

This folder contains the operational documentation requested for the current logging and debugging implementation.

Files:

- `project-overview.md`: architecture, execution flow, and where instrumentation now lives
- `debug-logging.md`: log schema, trace artifacts, timing data, failure capture, and how to inspect runs
- `testing-and-verification.md`: practical commands for validation, smoke testing, and post-run analysis

Recommended reading order:

1. `project-overview.md`
2. `debug-logging.md`
3. `testing-and-verification.md`
